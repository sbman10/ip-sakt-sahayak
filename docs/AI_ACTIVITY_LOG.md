### Changes made

#### Backend files added

- `backend/requirements.txt` — minimal dependencies for FastAPI, Uvicorn and Pydantic.
- `backend/app/main.py` — creates the FastAPI application, CORS policy for local Vite origins, router registration and `GET /health`.

- `backend/app/schemas/chat.py` — validates `question`, `jurisdiction`, `language`, citations, confidence and disclaimer fields.
- `backend/app/__init__.py`, `backend/app/routers/__init__.py`, `backend/app/schemas/__init__.py` — make the backend modules importable.
- `backend/README.md` — gives the team local virtual-environment, installation and Uvicorn run instructions.

#### Frontend changes

- `ip-sakti/src/App.jsx` now imports `useEffect`.
- The typewriter hook now uses `useEffect` for its timer lifecycle. Previously it used `useState`, so the timer did not start as intended.
- `ChatPage.handleSend` now sends a JSON `POST` request to `VITE_API_BASE_URL` or local FastAPI at `127.0.0.1:8000`.
- The UI sends the current question, jurisdiction and language.
- The UI renders the backend answer and supports loading, HTTP-error and unavailable-backend states.
- The simulated `setTimeout` chat response was removed from the send path.

### Deliberately not added

- No LLM or Gemini/OpenAI key.
- No RAG retrieval, embeddings, vector database or citations generated by AI.
- No PostgreSQL, SQLAlchemy or Alembic.
- No authentication, Redis, Celery, OCR, scraping or multilingual translation service.
- No Tailwind/shadcn migration; the project’s Rules.md says to keep Vanilla CSS for this stage.

### Why this milestone was chosen

`AyuSync.md` defines a real React → API → Python milestone before corpus ingestion and RAG. This change proves the data flow with transparent placeholder data, so the team can understand and test the architecture without presenting an ungrounded AI answer as real.
