description: Managing the learning journal documentation
---

Use this workflow to clean and update the learning log:

1. **Focus on Core Concepts:**
   - Add entries for major technical topics (FastAPI, RAG, Cosine similarity, PyMuPDF, etc.).
   - Refrain from adding notes on trivial code adjustments.

2. **Style of Explanations:**
   - Use clear, student-friendly terms.
   - Use simple analogies and Hinglish explanations for complex ideas.

3. **Verify Documentation Structure:**
   - Keep the core terms list clean and alphabetical.
