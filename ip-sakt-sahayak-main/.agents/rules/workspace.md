# IP-SAKTI Sahayak

---

## 1. Project Context

You are working on IP-SAKTI Sahayak (SIH 2026, Problem Statement 26045). This is an Ayurvedic intellectual property retrieval system.

## 2. Mandatory Setup Inspection

Every time you are initialized, you MUST:
1. Inspect `docs/Rules.md` to learn about constraints, non-fabrication policies, and commenting rules.
2. Read `docs/Memory.md` to see the current status of workspace features.
3. Review `docs/Phases.md` to verify current tasks.

## 3. Strict Development Actions

- **Preserve Safety:** Never invent laws, acts, sections, or citations. If queries have no citations in the retrieved context, report that you cannot find the answer.
- **Annotate Changes:** Any edits to files must follow the `# ADDED:`, `# UPDATED:`, `# REMOVED:` commenting protocols.
- **Separate jurisdictions:** Strictly keep Indian statute contexts separate from international treaty lists.
- **Explain concepts:** Since students are learning, explain your edits using analogies and simple terms.
- **Update Documentation:** If you update features, update `docs/Memory.md` and `docs/CHANGELOG.md` to reflect the new state.
