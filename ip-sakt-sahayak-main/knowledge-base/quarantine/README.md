# Quarantine Directory

This directory holds candidate sources, secondary materials, and incomplete records that DO NOT yet meet the full criteria for authoritative primary knowledge packages.

## Subdirectories
- `pending-verification/` — Primary sources awaiting official verification of gazette number, edition, or official URL.
- `secondary-material/` — Authored summaries, FAQs, guides, and synthesized knowledge files (e.g., the 47 curated JSONL files) that lack attached primary gazette documents.
- `incomplete-case-law/` — Case records lacking certified judgment PDFs, docket numbers, or official court citations.
- `incomplete-registry-records/` — Registry entries lacking certified application numbers or journal extracts.
- `rejected-sources/` — Inauthentic, superseded without lineage, or unverifiable documents.
