# Indian Pharmacopoeial Standards

Authoritative statutory standards, monographs, and formularies recognized under the Drugs and Cosmetics Act, 1940 (Second Schedule).

## Sub-disciplines
- `ayurvedic-pharmacopoeia-of-india/` — Ayurvedic Pharmacopoeia of India (API)
- `homoeopathic-pharmacopoeia-of-india/` — Homoeopathic Pharmacopoeia of India (HPI)
- `indian-pharmacopoeia/` — Indian Pharmacopoeia (IP)
- Unani & Siddha Pharmacopoeia

## Requirements
- Formularies must reference the specific edition, volume, and publication gazette.
