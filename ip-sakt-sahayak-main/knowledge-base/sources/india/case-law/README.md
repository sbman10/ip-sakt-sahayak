# Indian Case Law

Judicial decisions from the Supreme Court of India, High Courts (including IP Divisions), and intellectual property tribunals (IPAB/Commercial Courts).

## Required Metadata Standard
Case law entries MUST conform to `knowledge-base/schemas/case-law.schema.yaml` with:
- Formal citation & Neutral citation (where available)
- Court name & Bench composition
- Judgment date & Verified PDF judgment copy from the official court repository
