# India Treaties

This directory is designated for bilateral and plurilateral treaties, MOUs, and international agreements entered into by the Government of India pertaining to AYUSH, biodiversity, traditional knowledge, and intellectual property.

## Contribution Standards
- Primary sources must include official Ministry of External Affairs (MEA) / Ministry of Ayush / DPIIT certified copies.
- Each source package must conform to `knowledge-base/schemas/source.schema.yaml`.
